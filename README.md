# Integration Bee

Public study pack for the UK University Integration Bee.

A learner talks to an assistant. The assistant reads `AGENTS.md`, then `.cursor/skills/integration-bee-companion/SKILL.md`, and uses `scripts/control-integration-bee`. The learner does not run commands.

## Start here

1. Read `AGENTS.md` for setup and `make check`.
2. Teach from `units/` with the files in `templates/`.
3. Official contest PDFs stay out of git. Download them with `sources/fetch.sh`. The committed list is `past/inventory.json`.
4. The Yang Topics Guide, 2nd edition, is `sources/user/Integration_Bee_Topics_Guide_Yang_2nd_Ed.pdf`. Attribution is in `sources/user/README.md`.

Syllabus links are in `syllabus-map.md`. The skill tree is `skill-tree.md`.
