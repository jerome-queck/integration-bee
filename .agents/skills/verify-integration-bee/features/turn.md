# Turn

The companion sends one JSON turn. The CLI teaches, marks a photo extract, opens a mock, places an aptitude probe, confirms a skip, and sets full coverage.

## Sub-features

- `turn-show` prints the idle session and writes nothing.
- `turn-teach` serves `U01-D07` with the answer hidden and stores phase `awaiting_answer`.
- `turn-mark` records a wrong photo extract, then a correct one, and reads both from `progress show`.
- `turn-mock-blocked` refuses a mock before Round 1 nodes are solid.
- `turn-sample` grades the SAMPLE catalog with SymPy, including Q05, Q08, Q09 and Q19. It accepts the printed Q08 parameter `s`, retains additive constants for Q19, and rejects the Q15 printed sign. The two answered Yang examples also grade without a verdict.
- `turn-method-gap` stores a correct final answer with a wrong method as a mark row and a technique card.
- `turn-catalog-mark` grades the resolved 2022 Q01 trio as `1` without a verdict, rejects the conflicting `sin(1)` marks even with a correct verdict, and refuses an unanswered Yang practice problem. Pack manuals are 0 and sample manuals are 0. A synthetic catalog row in `turn_contract_check.py` preserves manual-verdict coverage.
- `turn-aptitude` opens `U01-D07` in phase `aptitude` and hides the answer.
- `turn-aptitude-drill` stores a correct `0` and opens `R1-2022-MIT-TB-Q01` without a skip.
- `turn-catalog-probe` grades `1` automatically for that contest row, writes no skip, and proposes `basic-integration`.
- `turn-confirm-early` refuses `confirm` before that offer exists.
- `turn-confirm-decline` accepts an empty node list and writes no skip.
- `turn-confirm-outside` refuses an id that the offer left out and writes nothing.
- `turn-confirm-skip` writes `skipped` for `basic-integration` and leaves the mock blocked.
- `turn-cover` sets full coverage, puts that node back on the coach queue, and still blocks the mock.
- `turn-skip-miss` stores a miss on that drill and sets the tick back to `learning`.
- `turn-gap` stores a gap id on the attempt, names one teaching file in `say`, and leaves the note files unchanged.
- `turn-syllabus-evidence` uses explicit floor/DUTIS drills, keeps optional recognition outside automatic mastery, and preserves the 20-node Round 1 gate.

## How to get to it (user POV)

- The learner asks for a concept, sends a photo of a solution, asks for a placement probe, or asks for a timed mock. The companion sends the turn. The learner does not run the CLI.

## Gotchas

- A second `teach` while a drill is open repeats that drill.
- An unparsable answer and a manual problem with no `verdict` exit 2 and write nothing. A manual verdict stores the companion's judgment and does not send the lossy integrand to SymPy; `turn_contract_check.py` exercises this path with a synthetic catalog row so it does not depend on a source hold. The resolved 2022 Q01 trio is `sympy` and grades `1`, while the different `R1-2024-Q01` still grades `sin(1)`. Send `extract.final_answer` without a verdict for proved rows. A verdict does not make a wrong expression correct.
- `YANG-1.1-P01` has no printed answer. A verdict on that id exits 2 and adds no attempt.
- `mock-start` with `"cold": true` bypasses the Round 1 gate. The blocked proof must omit `cold`.
- A second `mock-start` while an unscored mock is stored keeps that mock. A different pack says `The open mock stays`. `mock-finish` for another id exits 2 with `open mock is`. An empty turn during `mock_open` repeats the open mock and leaves the phase `mock_open`.
- `mock-start` with `pack` `pdf-round1` and `year` 2021 reports `count` 40 and `on_disk` true. The problems PDF is `sources/past/r1/2021/2021_Round_1_UK_University_Integration_Bee.pdf`.
- `verify/turn_contract_check.py` also drives the second placement probe, the 2021 pack, and the open-retry gap fill. `make check` runs it from `verify/run.sh`. The feature drive records its own transcript for `turn show`, teach, mark, aptitude, confirm, cover, and the sample grades. `SAMPLE-Q17` accepts `E*x+C` and rejects `ln|ln x|+C`.
- A correct mark with `method_note` writes `marks.json` (`method_ok` false) and `stickies.json` (one card, no stored strength). A repeat of that same answer while the problem is still open does not append a second attempt. A wrong final answer does not invent `method_ok`.
- `extract.gap` is one of the six headings in `docs/techniques/beyond-yang.md`. `say` names that heading's file. `turn apply` stores the id and does not write the file. A unit miss with no gap names `units/{unit}/teaching.tex` and does not name the index.
- A photo mark may set `image` to a file path. The CLI copies it to `submissions/<IB_USER>/` under the data directory. `mark.picture` and `progress show` name that relative path. A missing file exits 2 and writes nothing. A typed mark does not take `image`. A suffix other than `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, or `.heic` exits 2 with `image type not stored`. `IB_USER` `learner.1` selects `submissions/learner.1/`. A value that still contains `..` after cleaning, such as `a..b`, selects `submissions/default/`.
- `mock-start` while the phase is `awaiting_answer` or `aptitude` exits 2 with `an integral is still open`. While the phase is `proposing`, it exits 2 with `confirm the skip offer first`.
