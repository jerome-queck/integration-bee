# Round 2 coach

Group, crossnumber, and relay. The 2021 shuttle file is the relay. Clocks, point values, the attempt-shape table, and the score of a stored drill are `docs/techniques/formats.md`. This file is the session order. A formats miss still teaches that note, because `say` names one file.

## Order

1. Name the game: group, crossnumber, or relay.
2. If the integrand's catalog node is missing or `learning`, teach it from `pedagogy/round1-coach.md` and stop. The format minute starts when that node is solid, or when the learner asked for the game.
3. Read the attempt-shape row and the matching vignette under "Score a stored drill".
4. Set the one drill that vignette names. The learner writes the object in that row.
5. After they answer, say the format points. The mark turn still records the drill as correct or incorrect. Quote the stored value from the unit note. Leave every pack file closed, including a note under `solutions/`.

## Dose

| Detail | What you do |
|---|---|
| worked | Read the format's section in `docs/techniques/formats.md`, then its vignette, then set the drill. |
| faded | Give the stored value. Ask only for the score line: the points, and the digit or the bonus when the game uses one. |
| bare | Name the game and set the drill. Hide the stored value. Score the object they wrote. |

Past-paper PDFs and a contest grid stay closed. The blank grid file named Crossword is the shape of a digit square. It is not a source of digits.

## Group

The object is the value. The clock is 60 minutes, ten problems, answers in at the end.

Say that a correct value is 6 and a blank is 0, and that `U14-D10` (stored value 2) earns the same 6 as `U20-D01` (stored value \(3\pi/16\)).

For a worked or faded dose, set `U20-D01` and use the group vignette. For a bare hour, set ten stored drills from one unit, hardest last. Skip a stuck drill. Six points on an easy drill are the full award for that line.

Name a miss when the learner asks for method credit, or when one stuck integral takes the hour.

## Crossnumber

The object is one digit, once. The clock is the 40 minutes in the 2024 guide. The formats note records the 2025 heading that says 60 minutes. Train to 40 unless the day's briefing names another clock.

Say the name of a clue. Leave the digit unsaid. One square is the ordinary submission. A whole clue cannot be withdrawn once checking has started.

For one square, set `U14-D10`. The stored value is 2, so the ink is the digit 2. For three squares from one integer, set `U14-D01`. The stored value is 120, so the digits are 1, then 2, then 0.

Name a miss when a square is tried twice, when the digit is spoken to the other half, or when the blank receives a full antiderivative.

## Relay

The object is the current problem only. The clock is 45 minutes, 20 problems.

Say that a skip is allowed and a return is not. A first correct attempt scores 3. A later correct attempt scores 1. The bonus is the count of correct problems: 0 for 0–9, 5 for 10–14, and 10 for 15–20. Count a later attempt scored 1. Leave a skip out of the count.

Set `U20-D08`. Keep `U20-D02` covered until `U20-D08` is answered or skipped. After that, `U20-D02` is the next drill. `U20-D08` stays closed.

Name a miss when an earlier problem is reopened, or when the bonus is treated as a consecutive streak.

## Closed during the lesson

A solutions note stays closed while the lesson is the format. `pedagogy/README.md` says when that note may be opened. The moment is after an answer to that id. The format lesson still uses a unit drill.
