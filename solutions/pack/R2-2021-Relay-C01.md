## Problem

\[
\int_{-1}^{1}\frac{\sin(\cot^{-1}x)+\cos(\tan^{-1}x)}{x^{2}+1}\,dx,
\]

## Solution

and pass on the square of the value, minus \(2\).

SymPy's \(\operatorname{acot}\) takes values in \((-\pi/2,\pi/2)\). For \(x<0\) the numerator is \(0\). For \(x>0\) it is \(2/\sqrt{1+x^{2}}\), so the integrand is \(2/(1+x^{2})^{3/2}\). The antiderivative of \((1+x^{2})^{-3/2}\) is \(x/\sqrt{1+x^{2}}\), and
\[
\int_{0}^{1}\frac{2}{(1+x^{2})^{3/2}}\,dx=\sqrt{2}.
\]
The value passed on is \((\sqrt{2})^{2}-2=0\). The mark scheme prints \(0\).

The problem PDF does not specify an arccot branch. Agreement with the mark
selects the signed convention \(\operatorname{acot}x=\arctan(1/x)\) for
\(x\ne0\); this is an inference from the source answer, not a stated domain
condition. Under the other common convention
\(\operatorname{acot}x=\pi/2-\arctan x\), the integral is \(2\sqrt2\),
and the pass-on value is \(6\). The certificate and the dependent C2/C3
parameters use the signed convention and do not claim branch independence.
