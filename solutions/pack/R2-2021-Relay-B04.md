## Problem

\[
\int_{1/c}^{\infty}\frac{\ln x}{x^{2}+\pi^{2}}\,dx.
\]

## Solution

The problem sheet (p. 3) says B3 passes its answer unchanged. The mark scheme (p. 4) records \(c=-\infty\). The printed relay therefore uses the reciprocal of this extended value as the lower endpoint \(0\); it does not specify an ordinary finite negative value of \(c\). Set \(x=\pi u\):
\[
\int_{0}^{\infty}\frac{\ln(\pi u)}{\pi(u^{2}+1)}\,du=\frac{\ln\pi}{2}+\frac{1}{\pi}\int_{0}^{\infty}\frac{\ln u}{u^{2}+1}\,du.
\]
The substitution \(u=1/v\) shows that the remaining integrand changes sign, so that integral is \(0\). The value is \((\ln\pi)/2\). The mark scheme prints \(\ln(\pi)/2\).

## Final answer

\[
\dfrac{\ln\pi}{2}.
\]
