## Problem

\[
\int_0^1\ln(1+x)\ln(1-x)\,dx.
\]

## Solution

The integrand is even, so the worked PDF writes

\[
\int_0^1\ln(1+x)\ln(1-x)\,dx=\frac12\int_{-1}^1\ln(1+x)\ln(1-x)\,dx.
\]

Set \(u=1+x\), then \(u=2t\):

\[
\int_0^1(\ln(2t))\bigl(\ln 2+\ln(1-t)\bigr)\,dt
=\int_0^1\bigl(\ln 2+\ln t\bigr)\bigl(\ln 2+\ln(1-t)\bigr)\,dt.
\]

Expand and use \(\int_0^1\ln t\,dt=\int_0^1\ln(1-t)\,dt=-1\), together with the value \(2-\pi^2/6\) of \(\int_0^1\ln t\ln(1-t)\,dt\) from problem 28 of the same paper:

\[
(\ln 2)^2-2\ln 2+2-\frac{\pi^2}{6}.
\]

## Final answer

\[
(\ln 2)^2-2\ln 2+2-\frac{\pi^2}{6}.
\]
