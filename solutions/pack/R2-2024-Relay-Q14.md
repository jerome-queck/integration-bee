## Problem

\[
\int_{0}^{2025}\bigl|1-\bigl|2-\bigl|3-\cdots-\lvert 2025-x\rvert\cdots\bigr|\bigr|\bigr|\,dx.
\]

## Solution

Write \(T_{n}(x)\) for the nest that starts at \(1\) and ends at \(\lvert n-x\rvert\), and set \(F_{n}(d)=T_{n}(n-d)\) for an integer distance \(d\). Unfolding the innermost absolute value gives
\[
F_{n}(d)=F_{n-1}(n-1-d)\quad(0\le d\le n-1),\qquad F_{n}(n)=F_{n-1}(1),
\]
with \(F_{1}(0)=0\) and \(F_{1}(1)=1\). The rule
\[
F_{n}(d)=\begin{cases}
d\bmod 2 & \text{if }n\equiv 0,1\pmod 4,\\
1-(d\bmod 2) & \text{if }n\equiv 2,3\pmod 4
\end{cases}
\]
obeys the same recurrence. It depends only on \(n\bmod 4\) and \(d\bmod 2\), and those cases match, so the rule holds for every \(n\). In particular \(T_{2025}\) equals \(0\) or \(1\) at each integer from \(0\) to \(2025\), and consecutive integers differ by \(1\).

Each absolute value in the nest changes slope only when its inside hits the integer being subtracted. Starting from \(\lvert 2025-x\rvert\), whose only kink is at an integer, every later kink stays at an integer. On each \([k,k+1]\) the graph is the straight line joining \(0\) to \(1\) or \(1\) to \(0\), of area \(1/2\). There are \(2025\) such intervals, so the integral is \(2025/2\).

## Final answer

\[
\dfrac{2025}{2}.
\]
