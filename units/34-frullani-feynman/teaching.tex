\section{Learning goals}

The catalog node \texttt{dutis} stays deferred. This unit is the later chapter.

\section{Worked parameter --- \texttt{U34-D05}}
For $a>-1$,
\[
\int_0^1 x^a\,dx=\frac{1}{a+1}.
\]
Differentiate in $a$:
\[
\int_0^1 x^a\ln x\,dx=-\frac{1}{(a+1)^2}.
\]
At $a=2$ the value is $-1/9$, the stored answer of \texttt{U34-D05}.
The drill file stores $x^2\log x$ on $[0,1]$. It does not store the parameter $a$.
