# Turn contract

The companion sends one JSON turn. `scripts/control-integration-bee turn apply` is the only command the skill names for teach, mark, and mock. The CLI writes the six tracker files and `session.json`. It projects `progress.local.json`. The companion does not append that file.

`practice`, `progress`, and `drills` stay. The feature map already proves them, and the turn planner calls the same writers. A second mark command would give the companion two doors.

A mark grades a drill or a `verify: sympy` sample with SymPy. An indefinite answer may differ by a constant. A definite answer may not. `practice check` stays an exact match. SAMPLE-Q17 accepts `ln|ln x|+C` and rejects the answers PDF `e^x+C`. A manual problem needs `verdict`, and a correct verdict is stored as a correct attempt. Two distinct correct drills for a node set that node to `solid`. The worked example stays a companion step and does not gate the tick, because the CLI cannot see the chat. A weak tag with fails is recommended before the next unfinished catalog node. The 60-minute and 10-minute reminders stay in the companion skill. The result carries `mock.started` and `duration_minutes`.

A repeated mark of the open problem with the same submitted answer does not append a second attempt. That covers a retry after the attempt was written and the session was not.
